# 保卫大肥鱼 · 云端花园

TDD 主案例见 [满级瓶子炮攻速光环](tdd/bottle_aura/README.md)，覆盖多来源光环、动态冷却、持续激光、穿透弹、范围攻击与暂停结算。专项测试位于 [tests/test_bottle_aura_tdd.py](tests/test_bottle_aura_tdd.py)，保存了真实 Red → Green → Refactor 输出与变更。

建塔交易作为基础案例，见 [过程记录](tdd/build_transaction/README.md) 与 [专项测试](tests/test_build_tdd.py)。

太阳灼烧已移除，恢复原有范围直击。瓶子炮达到三级后，给周围半径 160 像素内的其他炮塔提供 25% 攻速加成，不加成自身，多光环不叠加。魔法球保持连续激光，每秒伤害提高 25%；其余炮塔缩短发射或施放间隔，单次伤害、范围、弹速和减速时长不变。升级或出售光环来源立即改变加成，保留已完成的冷却进度。选中满级瓶子炮会显示金色光环圈，受益炮塔显示 +25%。

直接双击项目根目录的 **保卫大肥鱼-十关版.exe** 或 `start.bat`。这是包含 Python、Pygame 和全部素材的 Windows 单文件程序，无需安装 Python。新版沿用原有角色、星声和首通存档。

## 第八至十关与炮塔范围

- **08 砂岩绿洲**的怪兽从左下方进入，沿蛇形砂岩路向右折返。沙漠水井、羊角遗骨、仙人掌、砂岩堆、金币袋和绿洲均可击破。
- **09 风车回廊**的土路从上方风车旁出发，先向左绕过松林，再经过第二座风车抵达右下方。地图布置了青松、松林、树桩、岩石和池塘。
- **10 冰阶决战**的怪兽从右侧入口向上绕过冰道，沿阶梯形路线来到下方的守护角色。冰屋、冰岩、雪顶灌木和草莓冰棍可以击破。
- **月亮与太阳**的一级、二级、三级效果半径依次为 **128、136、144 像素**。地图上的射程圈、攻击特效、伤害和减速使用同一等级半径。

## 雪帽冰原与团子怪兽

- 第一关新增六个可破坏障碍，包括两组气球篮、彩虹云、金环星、橘环星和云上双松。大型障碍击破后会释放全部占用格。
- 顶部「选关」进入 **07 雪帽冰原**。怪兽沿冰砖从左下入口出发，经两段折返抵达右下方的角色。地图有冰屋、雪松、积雪圆木、金币袋、奶油塔、雪帽等 29 个可破坏障碍。
- 16 种食物怪分为快速、普通、重型三组。同组轮换出场，保留原有的血量、移速和金币奖励。
- 每关第五波全是该关专属团子。第 1～10 关依次是花结、蓝帽、紫缎、鹿冠、金羽、星坠、粉翼、琥珀、冰角、雪翎。团子基础生命 90，移速 56，击败奖励 14 金币，生命随关卡提高。

## 苔石溪谷与受击音效

- 顶部「选关」进入 **06 苔石溪谷**。石板路从右侧开始，多次折返后抵达左下角。橡果、苔石、绳栏和碧泉均可清除。
- 双环冰港的橡皮鸭使用新版黄色侧脸和粉色围巾。
- 右上角「设置」可分别开关背景音乐和音效，两项默认开启并自动保存。音效包含操作、建塔和受击。
- 三位角色每次因怪兽抵达终点而扣除生命时，完整播放从参考录像截取的「啊、哎呦」。连续扣血时，下一组等当前组播放完再开始。7 点和 3 点仍对应两档受伤立绘。

## 双环冰港与旋转炮头

- 顶部「选关」进入 **05 双环冰港**。每波怪兽交替从左右入口出现，绕行冰砖道路后从底部汇合。救生圈、漂流瓶、冰棍、橡皮鸭、冰晶和小艇均可破坏。
- 弓箭、瓶子炮、火箭的炮头独立瞄准，开火时产生短暂后坐。弹丸从炮口出发，火箭发射后保持原方向。
- 弓箭每次从炮口射出三根紫箭，范围伤害仍按单次齐射结算。

## 冰灯海湾与火箭塔

- 顶部「选关」进入 **04 冰灯海湾**。怪兽从右侧沿冰砖小路前进，灯塔、小艇、漂流木等 16 个障碍均可破坏。炮塔只能建在岛上空地。
- **火箭**需要 150 金币，建造快捷键为 8。一级射程 175，每 1.20 秒发射一枚红白火箭，沿直线飞行最多 450 像素，对沿途碰到的每个敌人或障碍造成一次 32 点伤害，无减速。
- 风扇弹丸改为青绿色五叶转子。月亮一级每 1.50 秒施放一次，慢于太阳的 1.05 秒。

## 风语林地、风扇与持续激光

- 顶部「选关」→ **03 风语林地**：全新草地与泥土回环路线，24 个可攻击障碍，包括树桩、岩石堆、2×2 松林和风车小屋。开局 260 金币，无预置炮塔。
- **魔法球**（160 金币）：改为持续紫色激光，一级每秒 60 伤害、射程 175。锁定一个实例持续输出，直到目标死亡、漏怪或离开射程；不会因其他怪兽超前而换目标。可手动指定新目标切换集火，支持攻击障碍。伤害按游戏时间计算，暂停与商店暂停时停止结算。
- **风扇**（120 金币，快捷键 7）：绿色五叶风扇造型，每 0.95 秒发射一片旋转叶片，索敌射程 165，叶片沿发射时的方向直线飞行最多 420 像素，速度 340。穿透沿途怪兽与障碍，每片对同一个实例仅造成一次 16 点伤害。
- 风扇命中的存活敌人速度降至 **75%**，持续 **1.4 秒**，显示绿色水晶。升级提高伤害、射程、飞行距离，并强化减速（每级再降低 5 个百分点）。
- **月亮**重做为金色月牙与紫蓝圆盘造型，发出一圈蓝色波纹。一级会将半径 128 内的敌人速度降至 **58%**，持续 **0.8 秒**，每 1.50 秒施加一次，显示蓝色水晶；不造成伤害。
- **减速不相乘，月亮优先**。两类效果各自计时，月亮生效时只使用月亮倍率和蓝晶；月亮结束后，若风扇尚未到期则恢复风扇倍率与绿晶。全部到期后恢复正常速度，水晶消失。重复命中刷新对应效果的时间，不会永久减速。

## 冰糖雪原与新炮塔

- 已移除全屏功能及对应按钮、快捷键、启动参数，固定为 1280×800 窗口。
- 顶部「选关」→ **02 冰糖雪原**，进入独立冰砖路线的地图。初始 245 金币，没有预置炮塔。
- 第二关共有 27 个可攻击障碍：冰晶、2×1 冰岩、2×2 冰屋与雪松。点击大障碍任一占用格可选中同一个目标；击破只发一次金币，并释放全部占用格。
- 冰晶 110 血 / 10 金币，冰岩 250 血 / 23 金币，冰屋 360 血 / 32 金币，雪松 280 血 / 26 金币。
- 新增 **太阳（140 金币）**：一级以自身为中心对半径 128 内的怪兽与障碍造成 20 伤害，间隔 1.05 秒，显示金黄色扩散日冕。范围内只有障碍时也会自动攻击，适合清障。大型障碍的边缘进入范围即受伤，每次攻击每个障碍只结算一次。
- **魔法球（160 金币）**：射程 175，持续单体激光，具体行为与数值见上方说明。
- 瓶子炮发射带拖尾的金色豆子；星星发射旋转的五角星。弹丸追踪发射时的目标实例，飞到目标后结算伤害。星星命中后以实际命中位置产生溅射。
- 弹丸不会因为点击了其他目标而转向。目标提前死亡时，豆子不伤害同位置的其他怪兽，星星在最后追踪位置爆炸；死亡目标不转移索敌标记。目标漏怪后对应弹丸消失。
- 每波开始前和清完后的准备阶段可布塔、升级和出售，炮塔与弹丸暂停。点击开始下一波后，炮塔恢复攻击，可在波次进行时手动索敌清理障碍。暂停或打开商店会同时冻结战斗和弹丸。

## 最终 Boss

- **第十关最后一波**的最后一名敌人是「手柄大魔王」：参考用户图片制作的橙色方块怪，抱着黑色游戏手柄。
- Boss 生命为 4392，移动速度 32，击败奖励 180 金币。登场时显示提示和独立生命条，可以点击集火，也会受到月亮减速、弓箭群伤与星星溅射影响。
- Boss 抵达终点扣除 **10 点生命**。最后一波必须击败它及剩余怪兽才能获胜；首通星声仍按原规则只领取一次。
- 可通过「选关」直接进入第十关挑战。建议升级伤害塔，配合月亮延长输出时间。

## 角色商店与星声

- 顶部「商店」进入金色展柜，打开商店会暂停战斗，关闭后恢复原来的暂停状态。
- 大肥鱼免费拥有，首次启动默认使用。GPT 娘与 Claude 娘各需 300 星声，初始星声为 600，恰好可兑换两位。
- 点击「兑换角色」购买，再点击「使用角色」即可切换地图上的被保护角色。三个角色使用相同的基地生命规则。
- 每关首次通关获得 100 星声，重复通关不会重复奖励。选关界面显示首通状态，胜利界面显示本次奖励。
- 星声、已购角色、当前角色和首通记录自动保存到 exe 同目录的 `saves/progress.sqlite3`。源码运行也使用项目目录下的同一存档。搬移游戏时一起保留 `saves` 文件夹。
- 购买与首通奖励使用数据库事务，重复操作或同时开启窗口不会重复扣款或领取。截图预览与自动测试使用独立存档。

## 玩法

- 第一关开局 230 金币、10 点生命，地图上没有预置炮塔。
- 点击地图空地，显示附近可放置格子与瓶子炮、月亮、弓箭、星星、太阳、魔法球、风扇、火箭八张卡片。再次点击塔种类才扣金币建造。
- 点击怪兽或障碍物，将它标记为全局优先目标。所有射程内的伤害塔优先攻击它。超出某座塔射程时，该塔继续自动攻击射程内的怪兽。
- 多个怪兽重叠时只选择画面最上层的一个实例。目标死亡或抵达终点后自动解除，不转移给同位置的其他怪兽。右键取消标记。
- 星糖树、水晶、宝箱分别有 140、200、240 生命，击破分别获得 12、16、22 金币，原格子随后可建塔。伤害塔通过手动标记攻击障碍物，弓箭与星星的范围伤害也能波及障碍物。月亮只负责减速。
- 道路、存活障碍物和角色区域不可建造。
- 悬停塔种类查看射程。右键或 Esc 取消选择。弹出菜单时也可用 1～8 建造，对应上面八种炮塔。
- 点击已建塔可升级（最高三级）或出售（返还累计投入的 70%）。
- 空格开始下一波。P 暂停或继续，暂停时仍可建造。顶部可切换倍速、选关或重开。
- 每波清完后手动开始下一波。漏怪扣生命，生命为零失败，全部波次清完且存活则胜利。
- 十关的敌人数、血量、波数逐步提升。首通记录会保存，对局中的炮塔与波次在重开时重置。

## 美术

按用户参考设计地图布局与角色。角色、炮塔、障碍图集、食物怪和团子立绘、部分地图背景和最终 Boss 使用内置 imagegen 生成。路线、界面和动态攻击特效由 Pygame 绘制。

素材位于 `assets/`，具体提示词与文件对应关系见 `assets/PROMPTS.md`。

## 源码运行与打包

需要 Python 3.10 或以上。

```powershell
python -m pip install -r requirements.txt
python main.py
python main.py --level 2
python main.py --level 3
```

本机已配置 `.venv`。源码检查与回归测试可使用下列命令。

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```

修改后重新打包（环境中需安装 PyInstaller）可运行 `build.ps1`。

- `config.py` 定义地图网格、路线、障碍物、炮塔和关卡数值。
- `model.py` 定义 Enemy、Tower、Projectile、WaveManager、Game，以及多格障碍与范围命中。
- `main.py` 实现输入、建造菜单、状态栏和游戏循环。
- `art.py` 读取素材、绘制地图与敌人，并兼容打包路径。
- `progress.py` 管理角色兑换、星声余额与首通存档。

瓶子炮 70 金币，22 单体伤害，间隔 0.6 秒。月亮 90 金币，每 1.50 秒施加范围减速，速度降至 58%，持续 0.8 秒。弓箭 110 金币，18 范围伤害，间隔 1.15 秒。

星星 130 金币，主目标受到 30 直击伤害。以该目标本次命中位置为圆心，半径 76 内的其他怪兽和障碍物各受到 12 溅射伤害，主目标不重复结算溅射。攻击间隔 0.95 秒，射程 165。自动索敌和手动索敌都使用同样的命中圆心，主目标被直击击杀也会正常产生溅射。

升级提升射程、攻速、伤害或减速强度。星星同时提升直击、溅射伤害和溅射半径。
